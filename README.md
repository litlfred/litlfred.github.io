# litlfred.github.io

The user site at https://litlfred.github.io/, served by GitHub Pages from `main`, root folder (no `gh-pages` branch).

It holds one thing: `404.html`, which sends old addresses of project sites that moved to another owner to their new home, keeping the path, query and `#fragment`:

| old | new |
|---|---|
| `litlfred.github.io/dth-hrh/...` | `worldhealthorganization.github.io/dth-hrh/...` |
| `litlfred.github.io/who-iris/...` | `worldhealthorganization.github.io/who-iris/...` |
| `litlfred.github.io/smart-ra/...` | `worldhealthorganization.github.io/smart-ra/...` (once Pages is off on litlfred/smart-ra) |
| `litlfred.github.io/smart-trust-demo/...` | `worldhealthorganization.github.io/smart-trust-demo/...` (once Pages is off on litlfred/smart-trust-demo) |

Add a line to the `moved` map in `404.html` when another repository moves.
